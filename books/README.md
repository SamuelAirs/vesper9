# Books that ship with the console

Text-only EPUBs of Standard Ebooks editions (https://standardebooks.org). The source texts are in
the United States public domain and Standard Ebooks dedicate their work to the public domain
(CC0 1.0). Illustrations and fonts are left out; the console reads text only.

Rebuild or add one: clone its source repository from https://github.com/standardebooks and run
`python3 scripts/pack-books.py <clone> ...`. The Library lists these after the books in
`data/console/library`; a file of the same name there takes their place.
