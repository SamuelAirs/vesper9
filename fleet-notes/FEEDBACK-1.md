# Sam's feedback after playing 0.3 on the real device, 2026-10-01 ~11:00 (his words, condensed)

Overall: "the games are great... a good collection. For a lot of them, I'd like to see more depth. I'd also like
more use of the lights." Sound design good where noticed. Likes educational games/instruments ("if I'm going to be
bored I'd prefer to be learning"). Likes interfaces that need only the button and the lamps (Light Trial).

Menu gesture: inconsistent between apps (hold in Echo Vault / Signal School gives a long beep). Wants ONE gesture
everywhere, "even if it has to be a weird combination of taps". Idea: tapping the case / microphone slot as an input.

Games
1. Orbit Lock: pretty good, fun, simple.
2. Moonrunner: potential, but background scrolling is jerky. Make it closer to Alto's Adventure: snowboarding,
   minimal controls, smooth.
3. Undertow: pretty fun, takes too long to ramp up; propulsion animation weak.
4. Echo Vault: doesn't get it, not very fun. Maybe if it taught Morse.
5. Light Trial: fun and simple; loves that only button + lamp are needed. Wants more like it.
6. Glyph Archive: not fun, slow. Don't delete; would prefer to be learning something.
7. Pulsar: expected to love it; with one button the lanes don't make sense; lamps underused. Asked whether it is
   random every time (it is).
8. Perihelion: excellent, by far the favourite.
9. Descent: extremely slow, boring; concept has potential.
10. Ricochet: okay.
11. Helix: clunky and unresponsive; turning only one way "kinda sucks".
12. Ballista: needs work; make it like Kitten Cannon (launch for distance; things slow, accelerate, bounce you).
New ideas: fishing minigame (Stardew Valley mechanics); a cookie-clicker style idle/incremental game ("don't be
afraid to get deep").

Instruments
1. Signal School: very good so far; needs depth if not there; wants more educational things.
2. Chronometer: good concept, very clunky; hard to set and start a custom timer.
3. Field Notes: works well; presentation/scrolling needs a touch-up.
4. Atmosphere: not sure it needs to be its own thing; could be bundled with other sensor instruments. Reads a little
   hot because of the case.
5. Node Scope: "doesn't do much for me".
6. Calibration: nice to have, not sure it belongs on the dashboard. (He turned the sound up.)
7. Lantern: pretty good, a little tricky to use.
8. Cadence: likes it; stopwatch and intervals could replace Chronometer if done right.
9. Ephemeris: "doesn't work"; not really necessary; insanely clunky to set a location. Has a USB GPS, a bit flaky.
10. Resonance: likes the lamp use; cool looking tool.
11. Oracle: done quite well; dice animation and noise satisfying.
12. (cut off; probably Telemetry)
12. Telemetry: nice, but not sure it needs its own thing.
